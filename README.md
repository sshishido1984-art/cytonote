# CytoNote

細胞検査士認定試験の一次筆記対策用、無料の非公式学習アプリ。

## 公開先

https://sshishido1984-art.github.io/cytonote/

GitHub Pages の main ブランチ /docs を配信元として利用。

## 教材と機能

- 2025年度62問の文献調査による独自解答・解説・根拠リンク。公式正答や専門家による監修済みを意味しない。
- 2014〜2025年度の公式過去問PDFへのリンク。問題本文・原本PDFは再配布していない。
- 単一・組合せ・複数選択の採点、復習、メモ、ブックマーク、途中再開、学習記録。
- データは利用者のブラウザ内に保存。JSONバックアップに対応。
- 2026年11月4日に24問、その後16問を追加し、全6領域・60問に拡充。2025年度120問のうち残り60問の解答整備は未完了。

## 更新

編集元は dist/、教材の編集元は build-content.mjs。

```sh
npm start
npm test
npm run pages
```

npm run pages で教材生成・テスト・docs/への反映を実施。変更をmainへpushするとGitHub Pagesが更新される。file://直開きは非対応。

## 保存先の変更

以前のSites版とGitHub Pages版はURLが異なるため、学習記録は自動共有されない。以前のサイトの「学習データ」からJSONを書き出し、新しいサイトで読み込む。

noindexを設定しているが、公開リポジトリとサイトは誰でも閲覧可能。URLによる認証・アクセス制限はない。
